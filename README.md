# BrazilianBooty — estudo

Arquivos públicos da página e do questionário, preservados em `brazilianbooty-estudo-completo.zip`. Extraia o ZIP mantendo as pastas.

Inclui HTML, JavaScript compilado, CSS, 43 imagens, áudio e a página do player. O questionário foi testado localmente até a apresentação em vídeo.

Para abrir: execute `python -m http.server 8000` na pasta extraída e acesse http://localhost:8000.

Limites: o vídeo, fontes, rastreamento e pagamentos dependem de serviços externos. O vídeo não teve reprodução confirmada. A página upsell.html retorna 404 no original.
